# Объём светом, тенью и цветом

Да, объём на сайте создаётся без 3D-библиотек: светом, тенью, рамками, слоями и цветом. Живое демо всех приёмов: `assets/obem-demo.html`. Главное правило: **один источник света на всю страницу**, сверху слева. Все тени уходят вниз вправо, все блики сверху.

## Готовые токены

```css
:root{
  --shade:70,45,25; /* цвет тени в тон фона, не серый */
  --sh-1:0 1px 1px rgba(var(--shade),.10),0 3px 6px rgba(var(--shade),.08),0 14px 28px -10px rgba(var(--shade),.22);
  --sh-2:0 1px 1px rgba(var(--shade),.10),0 6px 12px rgba(var(--shade),.08),0 30px 60px -18px rgba(var(--shade),.36);
  --sh-3:0 2px 2px rgba(var(--shade),.10),0 12px 24px rgba(var(--shade),.10),0 50px 90px -24px rgba(var(--shade),.42);
  --edge:inset 0 1px 0 rgba(255,255,255,.75); /* светлая кромка сверху */
}
```

## Девять приёмов

1. **Тень из трёх слоёв** (`--sh-2`): плотная у края, мягкая рядом, широкая далеко. Одна размытая тень выглядит грязным облаком.
2. **Кнопка, на которую падает свет**: градиент светлее сверху, светлая полоска сверху и тёмная снизу (inset), тень цвета кнопки. При нажатии тень уходит внутрь.
3. **Фото в рамке-паспарту**: светлое поле 10-14 px, тень снаружи, лёгкая тень внутри по краю снимка, наклон 1-2°. Золотая багетная рамка из градиента для картин.
4. **Пятно света и виньетка**: за фото тёплое радиальное пятно, на фото светлее угол со стороны света и темнее края.
5. **Выход за рамку**: предмет или вырезанная фигура перекрывает край карточки, `filter: drop-shadow` по контуру.
6. **Слои глубины**: дальнее светлее, бледнее, чуть размыто; ближнее контрастнее и с длинной тенью. Можно сдвигать слои от мыши на 6/12/22 px.
7. **Наклон и блик за курсором**: до 6°, только мышь, не на телефоне, с учётом «уменьшить движение».
8. **Цвет как глубина**: тёплое и светлое ближе, холодное и тёмное дальше.
9. **Фото на весь блок + матовое стекло**: затемнение снизу для читаемости, карточка `backdrop-filter: blur(12px)`, не больше 2-3 таких на странице.

Дополнительно:
- **«Пластилин» (мягкий объём)**: `inset 0 2px 1px rgba(255,255,255,.85), inset 0 -6px 12px rgba(var(--shade),.10)` плюс внешняя тень. Для плиток и цифр.
- **Рельефный текст**: `text-shadow: 0 1px 0 #fff, 0 2px 0 <тон>, 0 4px 8px rgba(var(--shade),.25)` для одной крупной цифры или слова.
- **Реалистичный телефон** из CSS (рамка-градиент, вырез, блик по стеклу) с живым чатом бота: лучше скриншота и легче видео.
- **Скотч и полароиды** для «дневниковой» подачи.

## Нельзя

Неоновое свечение, тени с нулевым смещением цветным ореолом, жёсткие тени без размытия (4px 4px 0) вне необрутализма, разные направления света на одной странице, 3D-сцены WebGL для эксперта.
