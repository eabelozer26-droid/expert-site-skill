# Видео на сайте и монтаж роликов

## Видео на странице

- **Фоновое видео первого экрана**: без звука, 6-12 секунд петлёй, 720p, H.264 MP4 1-3 МБ (плюс WebM), обязательно `poster` (кадр-картинка).
  ```html
  <video autoplay muted loop playsinline preload="metadata" poster="hero.jpg">
    <source src="hero.webm" type="video/webm"><source src="hero.mp4" type="video/mp4">
  </video>
  ```
- Пауза, когда видео не на экране (IntersectionObserver), и только постер при «уменьшить движение» и в режиме экономии трафика.
- Видео со звуком (обращение эксперта, отзыв) только по нажатию: обложка с живым кадром лица и кнопкой «Смотреть, 1 мин», субтитры всегда.
- YouTube и VK Видео встраивать «лениво»: сначала картинка-обложка, плеер загружается по клику.
- Короткие «живые» петли вместо видео: CSS-телефон с чатом, появление сообщений по очереди (легче любого видео).

## Сжатие (ffmpeg)

```
ffmpeg -i in.mp4 -an -vf "scale=-2:720,fps=30" -c:v libx264 -crf 26 -preset slow -movflags +faststart hero.mp4
ffmpeg -i in.mp4 -an -vf "scale=-2:720,fps=30" -c:v libvpx-vp9 -crf 34 -b:v 0 hero.webm
ffmpeg -ss 2 -i hero.mp4 -frames:v 1 -q:v 3 hero.jpg
```

## Монтаж коротких роликов для сайта и соцсетей

Правила монтажа:
- хук в первую секунду: самый сильный кадр или фраза;
- склейки в долю музыки, но раз в 2, 4 или 8 долей, не на каждую;
- один клип один раз: мало материала, делайте ролик короче (15 с);
- плавно вместо шторок: растворение через размытие, свечение, мягкий наезд; шторки и белые вспышки устарели;
- плёночный цвет: мягкий контраст, тёплый баланс, лёгкое зерно, без кислотной насыщенности;
- крупные подписи по 1-3 слова для просмотра без звука;
- безопасная зона в 9:16: сверху около 210 px и снизу около 310 px закрыто интерфейсом;
- проверка кадрами каждые 0,5 с и вокруг каждой склейки.

Рецепты для экспертов: «Экспертный Reels 30 с», «Личная история», «Говорящая голова и перебивки», «Промо курса», «До и после».
