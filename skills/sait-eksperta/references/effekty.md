# Эффекты: что брать, что нет


## Брать (лёгкие, чистый CSS или пара строк JS)

| Эффект | Чем сделать | Зачем |
|---|---|---|
| Кнопка приподнимается при наведении | CSS | отклик, ощущение объёма |
| Подчёркивание ссылки слева направо | CSS | аккуратное меню |
| Блоки появляются при прокрутке (один раз, снизу на 20-40 px) | CSS + IntersectionObserver | ритм без суеты |
| Строки заголовка выезжают из-под маски | CSS (overflow + transform) или GSAP | «дорогое» появление главного заголовка, один раз |
| Фон меняет цвет по секциям | IntersectionObserver или GSAP ScrollTrigger | явные цветные блоки, структура видна сразу |
| Параллакс слоёв от мыши 6/10/22 px | CSS-переменные + pointermove | глубина фото и карточек |
| Аккордеон FAQ с плавной высотой | CSS | вопросы клиентов |
| Тост «Заявка отправлена», галочка рисуется | CSS | обратная связь формы |
| Карточки при появлении лесенкой | Motion inView | подборки работ |
| Медленный наезд на фото (Ken Burns) | CSS transform 8-10 c | «кинематографичный» блок |

## С осторожностью (только одно на страницу)

- Бегущая строка логотипов СМИ (только реальные).
- Счётчик цифр (только реальные и понятные цифры).
- Карусель отзывов (лучше без автопрокрутки).
- Тёплый градиент с плёночным зерном: есть CSS-аналог без WebGL через SVG-шум.

## Не брать для эксперта

Глитч-заголовок, печатная машинка, переливающийся градиентный текст, аврора-фон, плазма, туннели, «цифровой дождь», конфетти, курсор-капля, 3D-сцены Three.js, горизонтальная лента с закреплением, захват колеса прокрутки, автоповорот карусели.

## Правила

- Одно авторское движение на страницу, остальное тихо.
- Всё отключается при `prefers-reduced-motion: reduce`.
- Наклоны и параллакс только для мыши: `(hover:hover) and (pointer:fine)`.
- Анимируй `transform` и `opacity`, не `width`, `height`, `top`.
- Тайминги: отклик 150-300 мс, появление 600-900 мс, замедление `cubic-bezier(.16,1,.3,1)`.
- Проверка плавности: открыть страницу на слабом ноутбуке или с замедлением процессора в инструментах браузера.
