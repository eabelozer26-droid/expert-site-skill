# Цвет

## Основа

- **Фон светлый и тёплый** (молочный, бумажный, тёплый белый). Полностью тёмный фон сейчас мейнстрим технологических компаний и быстро надоедает, для эксперта он холодный. Тёмные полосы допустимы как акцент (одна секция, подвал), но не весь сайт.
- **Нет неону и кислоте:** лайм, ядовито-розовый, электрик на тёмном. Насыщенные цвета только приглушённые: терракота, вишня, бутылочная зелень, ультрамарин, охра, слива.
- **Нет чистому чёрному и белому:** текст `#2B241E` вместо `#000`, фон `#FBF7F1` вместо `#FFF`. Нейтральные цвета подкрашивай основным оттенком.
- **Палитра из жизни эксперта:** цвета его фото, картины, интерьера, одежды, продукта. Пример: картина, написанная экспертом, даёт бирюзу, ультрамарин, розовый и золото.
- **Стартовые палитры по нише** в `references/nishi.md` (28 ниш, контраст проверен). Это отправная точка: подстрой под человека.

## Роли (5-6 токенов)

```css
:root{
  --paper:#F6F0E8;   /* фон */
  --paper-2:#ECE3D7; /* подложки, вторые секции */
  --card:#FCF9F4;    /* карточки, рамки фото */
  --ink:#2A231D;     /* текст */
  --ink-2:#6B5E52;   /* второстепенный текст, контраст не ниже 4,5:1 */
  --accent:#B4583A;  /* кнопки и главное, не больше 10% площади */
  --accent-2:#3F6E73;/* второй акцент для ссылок и иконок */
  --line:rgba(70,45,25,.12);
}
```

## Цвет как глубина

- Тёплое и светлое выступает вперёд, холодное и тёмное уходит назад. Кнопки и главное тёплым акцентом, фоновые подложки холоднее и тише.
- Дальние слои светлее и бледнее (воздушная перспектива), ближние насыщеннее и контрастнее.
- Тень цвета предмета, а не серая: у терракотовой кнопки тень `rgba(150,60,30,.45)`, у зелёной карточки зеленоватая.
- Фон секций меняется ступенями одного тона (`--paper` → `--paper-2`), а не случайными цветами.

## Контраст

Текст 4,5:1, крупный текст и кнопки 3:1. Серый текст на цветном фоне запрещён: подкрашивай текст в тон фона.
