# Чек-лист перед показом

Проверяй готовую вёрстку глазами читателя, а не код. Каждую правку перепроверяй.

## Смысл
- [ ] Фраза-обещание понятна за 5 секунд: кому, что получит, как.
- [ ] Каждый факт отвечает на «и что?» для клиента. Нет внутренней кухни (номера отделов, результаты внутренних тестов).
- [ ] Нет выдуманных отзывов, логотипов, цифр.
- [ ] Тексты прошли humanizer-ru или humanizer, нет «—».
- [ ] Кнопка действия на первом экране и повторена ниже.

## Вид
- [ ] Блоки явно различаются: смена цвета фона секций, а не один оттенок на весь сайт.
- [ ] На каждом экране есть фото, предмет или живая деталь. Есть списки, а не только абзацы.
- [ ] Асимметрия 38/62, отступы по шкале 8-13-21-34-55-89.
- [ ] Один источник света: тени в одну сторону.
- [ ] Нет неона, кислотных цветов, полностью тёмного фона, фиолетовых градиентов.
- [ ] Шрифты с кириллицей, не Inter/Roboto/Arial как голос сайта.
- [ ] Фото эксперта приличное и культурное, сцены от ИИ подписаны.

## Техника
- [ ] `python -I scripts/proverka_saita.py <папка>` без ошибок.
- [ ] Консоль браузера без ошибок, нет упавших запросов.
- [ ] 375 px: нет горизонтальной прокрутки, кнопки от 44 px.
- [ ] Проверено на 375, 768, 1280, 1440.
- [ ] Контраст текста 4,5:1. Компоненты со своим фоном (телефон с чатом, карточки) задают свой цвет текста, иначе на тёмной полосе он наследует светлый и пропадает.
- [ ] На 375 px ни один элемент не выходит за правый край (тени и декоративные подложки тоже), иначе телефон уменьшает всю страницу.
- [ ] Движение отключается при «уменьшить движение», страница не подвисает.
- [ ] Картинки сжаты, у всех `width`, `height`, `alt`.
