# Шрифты

## Правила

- **Только с кириллицей.** Проверка: `https://fonts.googleapis.com/css2?family=<Имя>` должен содержать блок `/* cyrillic */`. Без кириллицы (проверено 14.11.2026): DM Sans, DM Serif Display, Syne, Outfit, Fraunces, Space Grotesk.
- **Две роли:** выразительный шрифт заголовков и спокойный шрифт текста. Третий только для цифр или подписи от руки.
- **Не голос сайта:** Inter, Roboto, Arial, Open Sans, Montserrat (усталые и «шаблонные»). Как запасной системный шрифт можно.
- **Шрифты кладём рядом с сайтом** (woff2 в папке `fonts/`), а не тянем с Google по сети: в России сеть до Google бывает медленной.
- Размер текста 17-19 px, межстрочный 1,5-1,65. Заголовок первого экрана 56-96 px на компьютере, 38-48 px на телефоне. Межбуквенный у крупных заголовков от -0,01 до -0,03 em.

## Объёмный и «живой» текст

Шрифт тоже может давать объём, но в меру и только в крупных заголовках:
- **Тиснение:** `text-shadow: 0 1px 0 rgba(255,255,255,.7), 0 -1px 0 rgba(0,0,0,.12)` на светлом фоне: буквы «вдавлены» в бумагу.
- **Рельеф:** `text-shadow: 0 1px 0 #e9dfd2, 0 2px 0 #e2d6c7, 0 3px 6px rgba(70,45,25,.25)`: буквы чуть приподняты.
- **Фото внутри букв:** `background:url(photo.jpg) center/cover; -webkit-background-clip:text; color:transparent` только для одного слова на странице, и с запасным цветом.
- **Курсив-акцент:** одно слово заголовка курсивом или другим цветом (как у Marie Forleo «Love»), не больше одного на экран.
- **Буквица** в начале истории эксперта.

Не делай: градиентный текст, неоновое свечение, анимацию по буквам на каждом заголовке.
